工作项目经历

项目介绍

实现从 PICO 设备到 Magicbot Z1 人形机器人的实时全身遥操作流程： 采集头显、手柄、全身关节及手部输入，使用 GMR 将人体姿态重定向为 Z1 的关节状态，再通过 LCM 发送至机器人控制端。

我的工作

  • 独立完成 XRobotStreamer 到 GMR 再到 Z1 关节状态的实时数据处理流程。
  • 处理 Z1 关节顺序、关节限位、偏航角校正与动作平滑，提升遥操作稳定性。
  • 通过 LCM 以固定频率发布骨盆姿态、关节位置和关节速度，保障控制端输入时序稳定。
  • 将 PICO 扳机与握力输入映射到双灵巧手/夹爪控制，并加入暂停和默认姿态切换。
  • 根据实际运行效果持续调整输入映射与动作平滑策略，保持控制表现一致。

项目介绍

聚焦人体动作数据的采集与质量处理：将 PICO/XRobot 追踪结果整理为标准化文件， 保证数据可复查、可复用；完成多相机视频流到 SMPL-X 动作恢复的上游流程，并将轨迹整理为 BeyondMimic / Isaac Lab 可直接接入的 motion 数据，熟悉训练前的数据格式规范、回放验证流程及任务接入方式。

我的工作

  • 完成多相机视频采集、相机标定、序列组织与 SMPL-X 动作恢复流程。
  • 通过 PICO/XRobot SDK 采集人体关节位置、旋转和设备时间戳。
  • 处理重复时间戳和设备时间戳异常，避免采集结果出现停帧或时间轴塌缩。
  • 使用 One Euro 滤波、高频帧重采样与坐标原点修复，提升动作数据连续性。
  • 将处理后的数据保存为可读取的 NPZ，统一关节顺序、采样频率和姿态格式。
  • 将重定向结果接入 BeyondMimic / Isaac Lab 的 motion 管线，用于校验 motion csv、npz、replay 与训练入口之间的数据格式一致性。

项目介绍

进行人体动作到人形机器人关节轨迹的离线重定向与数据处理。 使用 GMR 处理 SMPL-X、BVH 等人体动作输入，编写脚本自动配置人体缩放，处理四元数姿态变换、 配置 IK 目标和关节权重，再通过 MuJoCo 观察机器人动作效果；同时使用 SOMA 完成 BVH 到机器人 CSV/PKL 的完整流程，并完成 BeyondMimic 基础训练流程验证。

我的工作

  • 熟悉 SOMA 的 scaler、retargeter 和 feet stabilizer 配置，处理人体与机器人之间的运动学差异。
  • 掌握 GMR 的数据输入格式，以及人体骨架到机器人 link 的映射、尺度和姿态偏置配置。
  • 开发 auto_tune_human_scale.py，根据参考帧的位置误差自动搜索人体骨架尺度，减少人工反复修改配置的工作量。
  • 开发 smooth_pkl.py、trim_pkl_frames.py 和 pkl_dataset_player.py，完成动作平滑、序列裁剪、批量处理和 MuJoCo 播放质检。
  • 完成 BeyondMimic 基础训练流程验证，熟悉任务配置、奖励项、动作频率与回放验证流程。
