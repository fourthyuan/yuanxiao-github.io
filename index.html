项目信息

实习项目 / 常州北航唯实智能物联创新中心 /

项目介绍

项目面向数字人实时动作驱动，基于 OpenPose 提取人体关键点，在 Unity3D 中驱动 FBX 数字人模型，完成从人体骨架表征到目标骨架执行的动作重定向流程。项目重点处理 源人体骨架与目标骨架在层级结构、关节朝向、骨长比例和自由度上的差异，保证动作迁移 结果的稳定性与自然度。

我的工作

  • 负责 FBX 数字人模型的骨骼绑定与骨架适配，梳理人体骨架与目标数字人骨架的关节对应关系、层级结构与初始姿态差异。
  • 基于 OpenPose 输出的人体关键点数据，完成坐标转换、关节映射与姿态驱动，打通从视觉感知到数字人动作执行的流程。
  • 结合 IK / FK 约束处理手臂、腿部等末端链路，修正因骨长差异与自由度不一致导致的动作失真与末端漂移。
  • 对动作结果进行插值、平滑与异常帧修正，提升实时驱动过程中的连续性与稳定性。

技术栈

  • IK / FK

在校项目（校企合作） / 常州库曼智能 /

项目介绍

项目面向工业作业前的环境重建与目标定位需求，将双目相机安装于六轴机械臂末端， 通过识别指定标识获取目标在相机坐标系下的三维位置，再结合机械臂末端位姿参数与 旋转矩阵，完成相机坐标系到机器人基坐标系的转换，实现目标在世界坐标系下的精确 定位。项目重点优化多拍照点位和机器人基坐标系变化场景下的适应能力，减少重复标定成本。

我的工作

  • 负责项目整体程序设计与算法实现，完成视觉识别、三维测算、坐标转换、通讯联调与文档交付。
  • 基于 OpenCV 和 C++ 完成标识识别，并结合双目标定、立体校正、立体匹配与视差估计实现深度测量。
  • 基于机器人学中的坐标系变换与旋转矩阵，完成相机坐标系、末端坐标系与基坐标系之间的位姿解算。
  • 设计并实现平面误差处理策略，修正双目测距在复杂环境下的定位偏差，降低 X / Y / Z 三方向误差。
  • 完成上位机与库曼六轴机械臂的以太网通讯联调与真机部署，在企业现场完成定位验证与项目验收。
