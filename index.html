项目介绍

该项目聚焦人体动作数据的采集和质量处理，与第三个项目的实时机器人遥操相互独立。 一方面验证多相机视频流到 SMPL-X 人体动作结果的处理流程；另一方面通过 PICO/XRobot 记录全身追踪数据，生成可供后续分析、重定向和数据集制作使用的标准化文件。

我的工作

  • 跑通多相机视频采集、相机标定、序列组织和 SMPL-X 动作恢复流程。
  • 通过 PICO/XRobot SDK 采集人体关节位置、旋转和设备时间戳。
  • 处理重复时间戳和设备时间戳异常，避免采集结果出现停帧或时间轴塌缩。
  • 使用 One Euro 滤波、高频帧重采样和坐标原点修复，提升动作数据的连续性。
  • 将处理后的数据保存为 GMR 可读取的 NPZ，并通过可视化工具检查数据质量。

PICO 数据采集

项目介绍

该项目聚焦人体动作到人形机器人关节轨迹的离线重定向和数据处理。 使用 GMR 处理 SMPL-X、BVH 等人体动作输入，设置脚本自动配置人体缩放，处理四元数旋转、 配置IK 目标和关节权重，再通过 MuJoCo 观察机器人动作效果；同时使用 SOMA 跑通 BVH 到机器人 CSV/PKL 的完整流程，为后续动作播放、数据集制作和机器人部署准备标准化数据。

我的工作

  • 熟悉 SOMA 的 scaler、retargeter 和 feet stabilizer 配置，处理人体与机器人之间的运动学差异。
  • 掌握 GMR 的 数据输入格式，以及人体骨架到机器人 link 的映射、尺度和姿态偏置配置。
  • 开发 auto_tune_human_scale.py，根据参考帧的位置误差自动搜索人体骨架尺度，减少人工反复修改配置的工作量。
  • 开发 smooth_pkl.py、trim_pkl_frames.py 和 pkl_dataset_player.py，完成动作平滑、序列裁剪、批量处理和 MuJoCo 播放质检。

项目介绍

搭建从 PICO 设备到 Magicbot Z1 人形机器人的实时全身遥操链路： 采集头显、手柄、全身关节和手部输入，使用 GMR 将人体姿态重定向为 Z1 的关节状态，再通过 LCM 发送到机器人控制端。

我的工作

  • 接入 XRoboToolkit Python SDK，读取头显、手柄、全身追踪和手部输入数据。
  • 实现 XRobotStreamer 到 GMR 再到 Z1 关节状态的实时数据处理流程。
  • 处理 Z1 关节顺序、关节限位、偏航角校正和动作平滑，提升遥操稳定性。
  • 通过 LCM 以固定频率发布骨盆姿态、关节位置和关节速度。
  • 将 PICO 扳机与握力输入映射到双灵巧手/夹爪控制，并加入暂停和默认姿态切换。
